# 16minds 🧠

A modern, offline Android personality assessment app built with Kotlin.

## Features

- 🧠 Interactive personality assessment
- 🎯 Custom scoring system for 16 personality types
- 🎨 Modern UI with animations and interactive elements
- 📊 Personalized personality results
- 🔒 Fully offline — no account or backend required
- 🔔 Local notifications

## Tech Stack

- Kotlin
- Android SDK
- Gradle
- Material Design
- Android Animations
